8. GitHub Actions + Argo CD Flow
================================

Even though the separate GitHub Actions repo will focus on CI, this Argo CD repo should still explain the full CI + GitOps workflow at a high level.

Suggested files:

docs/
├── 29-ci-and-gitops-flow.md
└── 30-image-tag-update-strategy.md

Flow to explain:

Developer pushes code
        ↓
GitHub Actions runs tests
        ↓
GitHub Actions builds Docker image
        ↓
Security scans run
        ↓
Image is pushed to registry
        ↓
Manifest image tag is updated in Git
        ↓
Argo CD detects Git change
        ↓
Argo CD deploys to Kubernetes

This connects the future ci-with-github-actions repo with this gitops-with-argocd repo.
